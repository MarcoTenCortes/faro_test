La bandera --cors lleva el identificador de esta extensión: sin ella, Chrome bloquea las respuestas. Y --print-logs hace que la terminal muestre cada llamada y cada error del servidor.

Si opencode arranca y se cierra al momento, mira el error de la terminal: «is not valid JSON(C)… InvalidSymbol 1:1» es un opencode.json guardado con BOM (guárdalo como UTF-8 sin BOM), e «InvalidEscapeCharacter» es un {env:…} o una ruta de Windows con barras sin escapar dentro del JSON.

Conectar con

Este sitio todavía no tiene claves configuradas. Se guardan en tu opencode local, no en el navegador. Jira y Confluence llevan cada uno su dirección y su token; un solo MCP sirve a los dos, y si viven en hosts distintos el otro queda enlazado a éste y no volverá a pedirlas.

En Cloud los tokens se crean en id.atlassian.com → Security → API tokens y el mismo vale para los dos productos: pégalo en ambos. En Server / Data Center cada producto tiene el suyo: tu perfil → Personal Access Tokens, en Jira y en Confluence.

Faro escribirá estas claves en la configuración global de opencode, en la carpeta de configuración de opencode: en el primero que exista de opencode.jsonc, opencode.json y config.json (si no hay ninguno, opencode crea opencode.jsonc). opencode reformatea el fichero y reinicia sus conexiones: si tienes una respuesta a medias en otra ventana conectada a este opencode, se corta.
